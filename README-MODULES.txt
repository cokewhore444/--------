ساختار ماژول‌بندی پروژه

- js/main.js: نقطه ورود و اجرای بخش‌ها
- js/data.js: داده‌های محصولات، پیشنهادها و دسته‌بندی‌ها
- js/Sections/Hero.js: اسلایدر بنرها
- js/Sections/Content.js: نمایش محصولات، پیشنهادها و مجموعه‌های SVG
- js/Sections/Footer.js: فوتر
- js/BookCard/BookCard.js: کارت محصول و اکشن افزودن به سبد
- js/utils.js: توابع کمکی

برای اجرا از Live Server یا npm run start استفاده کن. اسکریپت‌های محلی از index.html حذف شده‌اند و main.js ماژول‌ها را وارد می‌کند.
